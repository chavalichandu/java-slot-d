# Task 4 — Classes, Objects and Constructors

**Aim:** Explain how class definitions model parking-system entities and how
constructors create valid objects.

A class groups state and behavior; each vehicle, user, ticket or facility is
an object. Parameterized constructors initialise required values and reject
missing registration numbers or categories. `this` distinguishes an object's
fields from constructor parameters, while `super` delegates initialization
to a parent constructor.

See Task 4 in `../Assignment_Report.md` for object memory, constructor
variants and the reason a copy constructor is unnecessary for tickets.
